# إدارة مخزني
تطبيق ويب عربي بسيط يعمل محلياً دون إنترنت بعد فتحه أول مرة، ويخزن البيانات في المتصفح على نفس الجهاز.

## التشغيل
- افتح `index.html` في Chrome.
- أضف الأصناف وحدد وحدة كل صنف.
- سجّل الوارد والصادر؛ الرصيد يُحسب تلقائياً.
- لا يسمح النظام بصرف كمية أكبر من الرصيد.

## الملفات
- `index.html`: هيكل التطبيق.
- `style.css`: التصميم.
- `app.js`: العمليات والحسابات والتخزين المحلي.
- `manifest.json` و`sw.js`: دعم التثبيت والعمل دون اتصال عند استضافته عبر HTTPS.

## GitHub Pages
ارفع جميع الملفات إلى المستودع نفسه، من الجذر، ثم من Settings > Pages اختر Deploy from a branch ثم الفرع main والمجلد /(root). افتح الرابط الناتج مرة مع الإنترنت ثم يمكن استخدامه دون اتصال بعد التخزين المؤقت.

## تنبيه مهم
البيانات محفوظة على المتصفح والجهاز الذي أدخلها فقط. استخدم زر «تصدير نسخة احتياطية» بانتظام، وانقل ملف JSON إلى مكان آمن. لا تمسح بيانات Chrome أو بيانات الموقع قبل أخذ نسخة احتياطية.
